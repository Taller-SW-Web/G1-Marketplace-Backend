## Escalamiento de I-01 y entorno

Si no se puede ejecutar una prueba intermodular, registrar **frontera y causa observada**, ruta, fecha, revisión de G1/G6 conocida, estado HTTP y correlación sanitizada en la tarea afectada. Distinguir falta de credencial/contrato, proveedor no disponible, despliegue incorrecto y respuesta incompatible; no sustituir un error REAL por un fixture sin declararlo. Para I-01 usar el seguimiento de [SPECS](https://github.com/Taller-SW-Web/G1-Marketplace-SPECS/blob/main/plan/DECISIONES-Y-BLOQUEOS.md) y [Backend #201](https://github.com/Taller-SW-Web/G1-Marketplace-Backend/issues/201); para configuración, base y pipeline usar [#200](https://github.com/Taller-SW-Web/G1-Marketplace-Backend/issues/200), [#204](https://github.com/Taller-SW-Web/G1-Marketplace-Backend/issues/204) y [#206](https://github.com/Taller-SW-Web/G1-Marketplace-Backend/issues/206). Coordinar con los responsables G6/G7 por bloque cuando el contrato o la disponibilidad externa sea la causa. No se exige una reunión en horario fijo.
